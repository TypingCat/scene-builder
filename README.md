# Scene Builder
주행기록 장면 데이터 구축 프로그램

## 특징
TFExample 형식의 차량 주행기록을 고정 크기 슬롯의 장면 데이터 규격으로 변환·구축하는 프로그램이다. 차로 연결 정보 없이 점 단위로만 주어지는 도로에서 차로 중심선·노면선·지물을 복원하고, 진입·진출, 좌우 인접, 좌우 경계 관계를 기하 규칙으로 재구성한다. 도로를 일정 간격의 조각으로 나눠 새 식별자를 주고 참조를 다시 이어, 장면 한 장만으로 도로 구조를 해석할 수 있게 한다. 속도·가속도는 위치 관측에 칼만 필터와 RTS 평활을 적용해 추정하고, 슬롯을 채울 때는 자차와의 근접도를 공통 기준으로 삼는다. 파일 머리에 규격 정보를 기록해 규격이 다른 데이터의 혼입을 막고, 딥러닝 프레임워크 없이도 장면을 읽을 수 있다.

## 주요기능
1. 입력 확인: TFRecord 파일별 레코드 수와 용량 집계
2. 주행기록 해석: 91프레임 참여자 궤적, 신호 상태, 경로 후보, 도로 점 추출
3. 도로 조립: 폴리라인 생성, 진입·진출·인접·경계 연결, 교차로·고속도로 구간 표시
4. 장면 변환: 100프레임 정규화, 속도·가속도 추정, 자차 근접순 정렬·절단, 0.5 m 간격 재표본과 조각 분할
5. 신호·지물: 통제 링크 연결, 정지선 위치 산출과 정지선 지물 생성
6. 경로: 끊김 분할과 겹침 병합, 300점 재표본, 루트 1개 확정, 점별 최근접 링크 기록
7. 병렬 구축: 파일별 병렬 처리, 진행률 표시, 중단 후 이어서 구축
8. 장면 입출력: 샤드 저장, 번호로 장면 조회, numpy 복호
9. 유효성 점검: 키·형상·스탬프·열거형·참조·자차·방향·경로 순서·정차 자세 9개 항목
10. 시각화: 10초 재생 HTML, 정지 PNG, 여러 장면 격자 PNG

## 사용방법
1. 설치: uv를 설치한 뒤 프로그램 폴더에서 uv sync를 실행한다(Python 3.12와 라이브러리 설치).
2. 입력 준비: 변환할 TFExample 주행기록 파일(.tfrecord)을 한 폴더에 둔다.
3. 실행: 프로그램 폴더에서 uv run scene-builder <명령>으로 실행한다. count -i 입력폴더는 레코드 수를 확인한다. build -i 입력폴더 -o 출력폴더는 장면 데이터셋을 구축한다(--workers 병렬 수, 중단 후 다시 실행하면 이어서 구축). info -i 데이터셋은 요약을, dump -i 데이터셋 --index 번호는 장면 필드를 보여준다. check -i 데이터셋은 9개 항목을 점검한다(--sample 표본 수). view -i 데이터셋 -o 그림폴더 --index 번호는 재생 HTML을 만든다(--png 정지 그림, --grid 격자 그림).
4. 도움말: 인자가 빠지면 안내문과 예시가 나오고, -h로 옵션 설명을 본다.
